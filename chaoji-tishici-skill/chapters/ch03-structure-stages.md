# 第 3 章：逻辑的交接——结构的演进与深度控制

## 核心思想
结构的本质不是排版美学，而是**降熵装置**：用符号与层级把背景、指令、约束、示例做语义隔离，让模型从"概率续写"切换到"完形填空"。结构演进有五级，每一级都在解决上一级的新瓶颈。

## 本章框架

- **五阶段演进**（S＝结构权重）：
  1. **直觉式**（2022 底–2023 初，S≈0）：拟人化、无结构、单轮；把 AI 当"神灯精灵"；本质是抽奖。
     - 病根：注意力混淆（背景/任务/诉求/格式混成一锅）、权重不明、无法精准调试。
     - 边界：探索性、低精度需求仍适用（保留随机性与创造力）。
  2. **框架式**（2023 中–2024 初，S≈C）：要素填空、静态模板。
     - 三大经典模型：**BROKE**（背景/角色/目标/关键结果/示例）、**CRISPE**（能力角色/洞察/陈述/性格/实验）、**RTF**（角色/任务/格式）。
     - 进步：从"求助式表达"到"指挥式指令"；质量从主观判断变为可检查标准；示例设定下限。
     - 局限：静态僵化、表面分块实则易混、重结果轻过程。
  3. **结构化**（2024 初至今，S>C）：Markdown + 模块化（LangGPT 为代表）。
     - LangGPT 结构：`Role / Profile / Skill / Rule / Workflow / Initialization`。
     - 两个支点：**注意力隔离**（功能区清晰）、**低解析成本**（语法标签即索引）。
     - 进步：从机械执行到"模拟思考"（Workflow 铺认知跑道）；软建议变硬约束（Rule）；可模块化调优。
  4. **代码化**（伪代码）：Class 封装 + If-Else 分支 + For/While 循环 + 质量阈值自检。
     - 进步：身份从"描述"变"规则锁定"；统一处理变"特别处理"；单次生成变"自我打磨"。
     - 局限：理解门槛高、约束过强伤创意、强依赖模型能力（"逻辑崩塌"风险）。
  5. **自动化（AFP）**（2025 底至今，S=System）：结构即系统，人只下"意图"。
     - 三特征：自动化编排、自动化运行（Pull）、自动化监督（监察者逻辑）。
     - 局限：只适合复杂流程任务；要求用户能判断拆解是否合理；学习曲线高。
- **AFP 案例骨架（简历）**：`运行时协议（严格步进/后台静默/心跳信号）→ 系统内核 → 双核对抗引擎 → 执行工作流（Phase + [STOP]）→ 交互仪表盘`。

## 关键概念
- **降熵装置**：结构降低语义歧义与噪声。
- **完形填空**：划定边界后让模型"填最优解"。
- **注意力隔离 / 低解析成本**：Markdown 结构的两大功能。
- **逻辑崩塌**：过度精密的约束在弱模型上一次出错导致连锁失效。

## 心智模型
- **"结构是轨道，不是装修"**：轨道的目的是防跑偏，不是好看。
- **"级别不是高低，是匹配"**：简单任务用 AFP 是负收益。
- **"每一级都在补上一级的洞"**：框架补直觉的散，结构化补框架的混，代码化补结构化的软，AFP 补代码化的死。

## 反模式
- 用"请""谢谢""要专业一点"驱动专业任务。
- 框架式里把背景与指令混排（模型仍会混淆）。
- 代码化盲目套用（弱模型上必然崩塌）。

## 关键结论
1. 结构的功能是"压缩搜索空间"，因此越复杂任务越需要结构。
2. 五阶段是认知坐标，不是能力鄙视链——判断自己在哪一级，才知道下一步补什么。
3. AFP 的跃迁在于"从指令到系统"：人给意图，系统跑流程。
