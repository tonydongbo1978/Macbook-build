# 第 7 章：四步法过程复盘（五个真实场景）

## 核心思想
四步法的价值要在真实场景里验证。本章用五个场景各走一遍，重点不是"结果多好"，而是**每一步的输入输出长什么样**——让你能照着对自己的任务做一遍。

## 本章框架

- **五个复盘场景**：
  1. **撰写文献综述**：任务框架化 → 检索—筛选—归类—对比—提出缺口；内容结构化重点在"证据链与引用口径"。
  2. **产品设计与商业模式验证**：框架 = 用户—痛点—方案—验证—迭代；重点在"假设与反证"。
  3. **个人 IP 定位**：框架 = 能力盘点—受众—差异点—内容支柱—验证；重点在"变量捕获"（你是谁、能做什么）。
  4. **商业计划书**：框架 = 问题—方案—市场—竞争—模型—团队—财务—里程碑；重点在"常量"（投资人共识标准）。
  5. **全脑演讲**：框架 = 开场钩子—冲突—论证—故事—收尾行动；重点在"节奏与情绪"。
- **复盘的共性结构**（每个场景都按此走）：
  1. 痛点与目标 → 2. 任务框架化（走 A/B/C/D 哪条路径）→ 3. 框架内容化（常量/变量/算法）→ 4. 结构化（AFP 骨架）→ 5. 演示与迭代点。
- **可迁移的三条经验**：
  - 场景差异主要在"常量"（行业标准不同），框架骨架高度相似；
  - "证据/口径"类场景（文献、商分、BP）最需要确定性（If-Then）；
  - "表达/情绪"类场景（演讲、IP）最需要颗粒度（可执行的风格机制）。

## 关键概念
- **证据链**：结论—证据—口径的闭环。
- **假设与反证**：商业模式验证的核心动作。
- **内容支柱**：个人 IP 的可复用内容骨架。
- **节奏设计**：演讲的钩子—冲突—收束结构。

## 心智模型
- **"换了场景，先换常量"**：框架可复用，行业标准必须重填。
- **"证据类要确定性，表达类要颗粒度"**：两类任务的优化重点相反。
- **"复盘看结构，不看结果"**：结果有偶然性，结构才可复用。

## 反模式
- 直接抄某个场景的成品提示词（常量不匹配，跑出来不对味）。
- 复盘时只贴最终输出，不记录中间迭代（学不到方法）。

## 关键结论
1. 四步法在五类场景中通用，差异集中在常量注入。
2. 场景可按"证据型 / 表达型"分类，分别强化确定性与颗粒度。
3. 复盘的产出应是"可迁移的框架"，不是"这一篇的稿子"。
