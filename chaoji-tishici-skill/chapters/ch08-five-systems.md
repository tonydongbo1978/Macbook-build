# 第 8 章：五套 AFP 实战系统

## 核心思想
五个完整系统覆盖"创作、合规、公文、内容、销售"五类高频高价值场景。它们的共同结构是：**痛点 → 核心交付（完整提示词）→ 演示**；共同技术是 AFP 四要素的组合使用。

## 本章框架

- **五套系统与各自的 AFP 侧重**：
  1. **万能漫画工场**：分镜—提示词—风格一致性；侧重"内容编排 + 变量注入"（角色/场景/画风参数化）。
  2. **鹰眼法律合规审计**：条款扫描—风险分级—修改建议—谈判口径；侧重"确定性"（If-Then 硬规则 + 引用依据）与"双核对冲"（执行/审计）。
  3. **高效公文全链路写作**：格式规范—内容生成—审校—成文；侧重"SOP + 素材库"（模板与范文作为常量）。
  4. **全渠道爆款内容引擎**：选题—结构—多平台改写—发布包；侧重"多角色 + 分支"（不同平台不同规格）。
  5. **催眠式销售文案引擎**：人群洞察—痛点—主张—证据—行动号召；侧重"颗粒度"（把"打动人"拆成可执行的心理机制）。
- **五套系统的共性设计**：
  - 都有"运行时协议 + 分阶段 [STOP]"；
  - 都有"执行角色 + 审计角色"；
  - 都把"行业常量"（法条/公文规范/平台规则/消费者心理）写成独立模块；
  - 都用仪表盘收口，输出"下一步动作"。
- **可复用的交付形态**：不是"一段文案"，而是"一套可反复运行的生产装备"（含量规、模板、检查项、增值资产）。

## 关键概念
- **风格一致性**：漫画/内容类系统的核心难点（跨批次不漂移）。
- **风险分级**：法律审计的交付形态（高/中/低 + 依据）。
- **全链路**：从输入规范到最终成文的完整链路。
- **心理机制**：销售文案中可执行的触发点（锚定、损失厌恶、社会证明等）。

## 心智模型
- **"系统 = 常量模块 + 流程模块 + 质检模块"**：五套系统都是这个三段式。
- **"输出装备，不输出稿子"**：可复用的量规比单篇成品值钱。
- **"一致性靠模板与参数，不靠模型记忆"**。

## 反模式
- 把行业规范写在正文里（每次改规范就要重写提示词）。
- 只做生成、不做质检（法律/公文场景不可接受）。
- 追求"一套通吃所有平台"（规格差异必须分支）。

## 关键结论
1. 高价值场景的共同点是"错一次代价高"，因此质检角色是必需品。
2. 行业常量必须模块化，才能随规范更新而低成本维护。
3. 交付"装备"而非"成品"，是从工匠到产品经理的分界。
