# 第 2 章：从"任务"到"场景"——打造可复用的提示词资产

## 核心思想
一次性任务是"打工者心态"，可复用场景是"导演思维"。区别不在提示词长短，而在**你是在指挥动作，还是在定义标准**。

## 本章框架

- **西西弗斯困境**：每次从零写指令，改十遍才满意，下次换任务又全部作废——"每一次都推石头"。
- **两种提示词**：
  | | 任务型 | 场景型 |
  |---|---|---|
  | 逻辑 | 单点交付 | 定义标准 |
  | 类比 | 打工者接单 | 导演搭台 |
  | 结果 | 日抛型消耗品 | 可复利资产 |
  | 例 | "写一句咖啡广告语" | 定义品牌调性 + 痛点 + 禁用语 + 输出规格 |
- **核心公式**：`Prompt = Structure（结构）+ Content（内容）`
  - 结构决定**智商下限**（强制进入慢思考、阻断随意猜测）；
  - 内容决定**产地上限**（垃圾进，逻辑严密的垃圾出）；
  - 权重演变：1.0 时代 90% 内容 + 10% 结构 → 5.0 时代 20% 内容 + 80% 结构。
- **资产级提示词三大判定原则**：
  1. **可复用性**：换一个主体是否仍有效？换了就报错＝手工艺品；换了照样跑＝资产。
  2. **场景性**：你是在"调教演员"（纠结具体对象）还是在"搭舞台"（定逻辑底色、质量红线、变量接口）？
  3. **工作流重构**：它是"加速试错"（让你更快地改）还是"消灭试错"（一次就把标准固化）？
- **"零薪酬 CXO"**：一个场景型提示词＝一个永不离职的高管；成本不是钱，是**一次性支付的认知**（把经验编码）。

## 关键概念
- **导演思维**：不指挥每一步，而是定义规则、边界与验收。
- **结构/内容二分**：骨架与血肉。
- **变量接口**：留给用户填空的位置（聚光灯打在哪）。
- **质量红线**：及格线（如严禁"提升了""优化了"这类空词）。

## 心智模型
- **"换主体测试"**：提示词换一个产品/客户/岗位是否仍可用——最快的资产判据。
- **"搭舞台，不教走路"**：定义"走进来就自动变专业"的空间。
- **"消灭试错，而非加速试错"**：如果只是让你改得更快，那还是打工。

## 反模式
- 把品牌名、参数写死在提示词里（换客户即报废）。
- 用形容词描述风格（"专业一点""高级感"）——不可执行。
- 只优化单次结果，不沉淀结构。

## 关键结论
1. 资产的标志是"结构与内容解耦"：结构固定，内容可换。
2. 80% 篇幅用于结构，是专业与业余的分界。
3. 一次性认知投入，换边际成本趋零的复用。
