# 术语表（按拼音首字母分组）

## A
- **AFP（Auto-Flow Prompt）** — 作者提出的"自动化提示词"架构：把提示词写成可运行的系统（ch05）。
- **AI 观光客** — 一次性使用 AI、能力不累积的人（ch01）。
- **注意力隔离** — 用 Markdown 层级划分功能区，防止模型顾此失彼（ch03）。

## B
- **剥洋葱法** — 从"顶级专家会怎么做"出发，逐层拆解出可执行算法（ch04）。
- **闭环反馈** — 注意：本书指 AFP 中的"审计—打回—重写"循环（ch05）。
- **变速** — 略。

## C
- **常量（Constants）** — 该场景公认的规范、方法论、审美标准（ch04）。
- **超级提示词** — 基于算力冗余设计的、有结构逻辑与多维约束的深度指令集＝数字分身（ch01）。
- **场景型提示词** — 定义标准的"导演"式提示词，可换主体复用（ch02）。
- **程序化运行** — AFP 要素一：从 Push 到 Pull，AI 持流程主动拉取（ch05）。

## D
- **代码化提示词** — 第四阶段：伪代码（Class/If-Else/While）+ 阈值自检（ch03）。
- **决策摩擦** — 判断、取舍、校准的成本，AI 无法代劳的部分（ch01）。
- **导演思维** — 不指挥动作，而是定义规则、边界与验收（ch02）。
- **对抗模式（双核）** — A 执行、B 审计；核心是独立性约束（ch05）。

## F
- **分隔符隔离** — 用符号界定"数据非指令"的最基础防御（ch09）。
- **分镜/风格一致性** — 漫画类系统的核心难点（ch08）。
- **风险分级** — 法律审计的交付形态（ch08）。

## G
- **工作网** — 真实任务是非线性的网；SOP 是把它降维成可执行结构（ch05）。
- **估值模型** — Value = (Expertise × Structure) × Frequency（ch09）。
- **规则锁定** — 代码化用 Class 把身份与禁止项写死（ch03）。

## H
- **HUD（全景仪表盘）** — AFP 要素四：每轮重写状态以对抗指令稀释（ch05）。
- **隐形悖论** — 工具越强、人越累（ch01）。

## J
- **结构** — 提示词的逻辑容器、执行协议与约束边界，决定智商下限（ch02）。
- **降熵装置** — 结构的本质功能：减少语义歧义与噪声（ch03）。
- **渐进式** — 本书未用此概念（属 Skill 体系），勿混淆。

## L
- **逻辑减速带** — 用复杂度迫使模型进入慢思考（ch01）。
- **逻辑崩塌** — 过度精密的约束在弱模型上连锁失效（ch03）。
- **六种编排** — 串行、并行、串并行混合、迭代回环、锦标赛、模块化调用（ch04）。

## P
- **PMS（提示词管理系统）** — 像管理代码一样管理提示词（ch09）。
- **Pull 交互** — AI 主动拉取变量与确认，交互权翻转（ch05）。
- **Push 交互** — 人推着 AI 走，逻辑倒灌（ch05）。

## Q
- **情绪价值 vs 准确价值** — 单核模型倾向取悦用户，多核用对抗换准确（ch05）。
- **确定性** — 内容维度三：内置 If-Then 决策逻辑（ch04）。

## S
- **三明治防御** — 前置约束 + 用户输入 + 后置强化，对抗最近指令偏好（ch09）。
- **上下文密度** — 内容维度二：高相关、低于扰地注入专业知识（ch04）。
- **收缩/收口** — 算法四要素之一：防跑题、防冒犯、收束为下一步（ch04）。
- **[STOP]** — AFP 的强制停点，交互权翻转的锚（ch05）。
- **四步法** — 任务框架化→框架内容化→内容结构化→迭代优化（ch06）。

## T
- **套取攻击** — 诱导模型泄露系统提示词（ch09）。
- **贪心/平均解** — 单核模式倾向输出的"安全但平庸"答案（ch05）。

## W
- **五阶段** — 直觉式→框架式→结构化→代码化→自动化（ch03）。
- **伪代码提示词** — 用编程语法组织提示词（Class/If/For）（ch03）。

## X
- **系统 1 / 系统 2** — 快思考（概率抢答）vs 慢思考（推理）（ch01）。
- **心跳信号** — 每轮顶部输出的极简状态码（ch05）。
- **思维树** — 多候选生成 + 自审 + 收敛（ch01）。
- **相对路径** — 略（属 Skill 体系）。

## Y
- **元提示词** — 生产提示词的提示词（如 AFP 内容元提示词、任务框架化架构师）（ch06）。
- **元指令声明** — 把安全原则写成最高级公理（ch09）。
- **冗余红利** — 推理成本骤降 + 上下文暴涨带来的新空间（ch01）。
- **预设变量/变量接口** — 留给用户填空的位置（ch02、ch04）。

## Z
- **资产型提示词** — 换主体仍有效、可复利（ch02）。
- **执行工作流** — AFP 的 Phase + Step + [STOP] 结构（ch05）。
- **最近指令偏好** — 模型对最后一条指令权重更高（ch09）。
