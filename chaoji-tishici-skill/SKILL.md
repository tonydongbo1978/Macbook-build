## 核心框架与心智模型

**1. 一句话主张（ch01）**
算力已从"紧缺"变成"冗余"（成本降约 99%、上下文百万级），因此提示词的经济学反转：**token 便宜了，判断才贵**。超级提示词不是"更长的指令"，而是把人的判断标准**无损迁移**进 AI 的系统——它是你的"数字分身"。

**2. 核心公式（ch02）**
`Prompt = Structure + Content`
- 结构决定**下限**（逼模型进入慢思考），内容决定**上限**（垃圾进垃圾出）；
- 结构占比从 1.0 时代的 10% 升到 5.0 时代的 80%。
- 资产三判据：**换主体仍有效**（可复用）、**搭舞台不调演员**（场景性）、**消灭试错非加速试错**（工作流重构）。

**3. 结构五阶段（ch03，定位工具）**
直觉式（神灯精灵）→ 框架式（BROKE/CRISPE/RTF 静态契约）→ 结构化（LangGPT：Role/Profile/Skill/Rule/Workflow/Initialization）→ 代码化（Class+If-Else+While+阈值自检）→ **自动化 AFP**（结构即系统）。
- 每一级补上一级的洞：框架补"散"，结构化补"混"，代码化补"软"，AFP 补"死"。

**4. 内容三要素（ch04）**
`内容 = 常量 + 变量 + 算法`
- 常量＝行业规范与审美标准（职业底座）；变量＝本次独有信息（不是越多越好）；算法＝步骤/判断/分支/收口。
- 多数人只写变量 → 输出"像没受过训练的人在模仿专业"。

**5. 内容三维度 + 场景三维度（ch04）**
- 三维度：**颗粒度**（把"幽默"拆成机制）、**上下文密度**（专业知识浓度）、**确定性**（If-Then 决策）。
- 场景三维度：任务复杂度、思维流向（发散/聚拢）、步骤密度（少步骤/多步骤接力）。
- 六大编排：串行、并行、串并行混合、迭代回环、锦标赛、模块化调用。

**6. AFP 四要素（ch05，全书核心）**
1. **程序化运行**：Push（人推 AI）→ **Pull**（AI 持流程，主动拉取）；实现靠运行时协议（严格步进/后台静默/心跳）。
2. **任务工作流化**：`Step + [STOP]` 硬停点；五段式 Diagnosis → Context Injection → Blueprint → Execution Loop → Packaging。
3. **角色赋能**：双核对冲（A 执行 / B 审计）+ **独立性约束**（禁止赞美、默认不通过、惩罚性措辞）→ 用冲突换质量。
4. **全景仪表盘（HUD）**：每轮末尾输出极简状态（Phase / Deliverable / PASS-FAIL / NEXT），对抗长对话中的指令稀释。规范三字：简、尾、少。

**7. AFP 决策矩阵（ch05，最高杠杆的一步）**
| 认知负载 | 结构化要求 | 结论 |
|---|---|---|
| 高 | 高 | 最适用（统治区） |
| 高 | 低 | 用"创意版"（减约束） |
| 低 | 高 | 用"轻量版"（省事+一致） |
| 低 | 低 | **禁止使用**（纯负收益） |

**8. 四步生产法（ch06）**
任务框架化（4 路径：系统资料/多条提示词/经验复述/无素材互动）→ 框架内容化（内容元提示词）→ 内容结构化（嵌入 AFP 骨架）→ 迭代优化。
- 关键：第一步只求"粗"（阶段—步骤—判断点），第三步才"硬"。

**9. 资产化（ch09）**
`Value = (Expertise × Structure) × Frequency`，任一为零则总值为零。
- 三层防御：分隔符隔离、"三明治"、元指令声明——但作者承认只能**抬高攻击成本**，不能杜绝。

## 范围与限制

1. **文本来源**：原书 PDF 为扫描件，OCR 有明显错字（如"掌"作"堂"、"算力"作"算刀"）；本技能基于正文重构，个别术语已按上下文校正，但**代码与表格细节可能有偏差**，引用原文时请对照正版。
2. **技术归因存疑**：书中把"长提示词逼出慢思考"解释为机制性原理，但现代推理模型的 thinking 主要由训练与推理预算决定；"暴力美学"可能只是相关性，不是因果。
3. **六大编排模式只给了清单**，未给每种模式的判定标准与成本对比——实际选型仍需经验。
4. **攻防部分偏弱**：三层防御都是"前端提示词防御"，真正的解法是不要把秘密放进提示词（架构层面）。
5. 模型版本（Gemini 3.0/GPT-5.2/Claude 4.5）是 2026 年初快照，会快速过期。

可长期复用的是**方法层**：结构/内容二分、常量+变量+算法、四要素、决策矩阵、估值公式——这些与具体模型无关。
