# 玩转 Skill：零门槛打造你的 AI 数字员工
**作者**：程希冀（C 哥） | **出版**：机械工业出版社，2026 年 4 月（174 千字，12 章 4 篇） | **生成**：2026-10-22

- **不带参数**：加载下面 8 条核心框架，可直接用于写/评 Skill
- **带主题**：如"三级约束""对话萃取""上下文"，先查主题索引再读章节

## 核心框架与心智模型

**1. 五级进化阶梯（ch01）**
提示词（怎么说）→ 工具调用（能不能做）→ MCP（怎么统一连）→ 智能体（能不能自己干）→ **Skill（能不能干得专业）**。层层叠加，不互相替代。
- 判断：一次性→提示词；要实时/操作→工具；多服务→MCP；多步自主→智能体；专业+稳定+重复→Skill。

**2. 四件套（ch02）**
```
my-skill/
├── SKILL.md        # 必需：YAML 元数据 + Markdown 指令
├── references/     # 选填：要"看懂"的知识
├── scripts/        # 选填：要"执行"的代码
└── assets/         # 选填：拿来就用的模板/素材
```
- 元数据只有 `name`（小写连字符、禁中文）与 `description`（可用中文，**是触发与否的唯一依据**）必填；可选 license/compatibility/metadata。
- 正文建议含：使用场景 / 工作流程 / 输出格式 / 注意事项；**≤500 行、≤5000 tokens**。

**3. 渐进式披露（ch02）**
元数据层（启动时全量加载，极小）→ 指令层（判定要用时加载 SKILL.md 全文）→ 资源层（按需读 references/调 scripts）。任务结束即释放。
- 意义：可以同时拥有几十种专业能力，却不拖垮推理质量。

**4. 五条设计标准（ch06，验收表）**
① 元数据准（第三人称，写清输入—输出—何时触发）
② 边界清（正向条件 + 易混时补负向条件）
③ 输入输出明（必需/可选分别列，输出结构写死）
④ 步骤可执行（动词开头；给框架不穷举）
⑤ 失败处理全（打不开/太短/不是这个/缺信息，每种给一句应对）

**5. 评估驱动、失败优先（ch06，最该学的方法）**
先裸跑 → 失败点即需求清单 → **先写考题**（输入+期望，含稳定性）→ 最小 Skill → 每次改动回归全部用例。
- 考题不写进 Skill（否则等于泄题）。

**6. 三级约束（ch08，选型的核心工具）**
| 级别 | 适用 | 判断法 |
|---|---|---|
| 策略指引 | 容错大、做法灵活（文案/审稿/建议） | 10 人做各有千秋但都对 |
| 模板框架 | 格式固定、内容灵活（报告/工单） | 10 人格式同、内容不同 |
| 程序脚本 | 必须精确（计算/转换/批量/校验） | 10 人结果都一样 |
原则：能策略就不上模板，能模板就不写脚本。

**7. 上下文工程（ch06）**
一句话：**能在上下文外干的活，不要搬进来**。三招：脚本算完只输出结论；脚本内调 API 批量预处理（可换便宜模型）；子智能体隔离中间过程。

**8. 知识与治理（ch07、ch12）**
- 知识库：先全转纯文本；按业务结构分目录；**文件名即索引**；`索引.md`；引用写到文件级；粒度用"5 文件法则"检验。
- 治理：个人＝分类/索引/备份；团队＝权威来源/负责人/索引文档/季度审查；版本用 Git。

**9. 隐性知识萃取（ch05，全书最独特）**
不写，而是"聊"：AI 扮好奇新人追问（为什么/如果/依据）→ 讲真实案例 → 归纳规则 → 新案例验证 → 转 SKILL.md。
- 卡住时：举反例 / 回忆更多场景 / 让 AI 猜（"不对，是因为…"往往就是隐性知识）。

**10. 安全底线（ch03）**
四类威胁：数据泄露、权限提升、供应链、提示词注入。五条实践：来源审查、权限最小化、执行前预览、敏感操作确认、信任分级。
- 补充：把 SKILL.md 与脚本交给"无工具权限"的网页版 AI 做安全审查。

## 范围与限制

1. **工具细节会过期**：第 4 章的平台路径、第 3 章的模型梯队都是 2026 年初快照，各平台改版频繁——路径类信息务必以官方文档为准。
2. **本书是教程，不是评测**：12 个案例是"配方"，没有报告失败率、成本或对照实验；引用其效果时需自行验证。
3. **PDF 提取损耗**：原书 311 页，纯文本提取缺失约 27 页（整页截图），图表与代码示例未完整保留；本技能基于正文重构。
4. 书中对模型能力的排名（T1/T2/T3、"90% vs 30%"）无公开来源，属经验判断，且半年即可失效。

最可靠的部分是**方法层**：五标准、三级约束、评估驱动、对话萃取——这些与具体工具无关，可长期复用。
