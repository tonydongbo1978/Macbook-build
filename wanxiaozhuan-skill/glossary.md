# 术语表（按拼音首字母分组）

## A
- **AgentLoop（智能体循环）** — 规划→执行→观察的持续循环，Skill 在其中被反复消费（ch03）。

## B
- **闭包反馈/闭环反馈** — 关键节点"验证→修正→继续"，防止错误累积到终点（ch06）。
- **变量（预定义）** — Skill 加载时被替换的值，如 `$ARGUMENTS` 接收用户输入（ch03）。

## C
- **策略指引** — 三级约束中最轻的一级：只给原则与维度，不给步骤（ch08）。
- **策略方案模式** — 一次输入输出完整应对方案，适合熟练者（ch05）。
- **程序脚本** — 三级约束中最重的一级：逻辑写死，只传参（ch08）。

## D
- **单一职责** — 一个 Skill 只做一件事（ch06）。
- **对话萃取法** — 让 AI 扮采访者追问，把隐性知识显性化（ch05）。
- **多级查阅** — 先索引/概述再深入详情，适合海量知识（ch07）。
- **多轮辅助模式** — 每轮给下一步建议，适合新手（ch05）。

## F
- **分级约束/三级约束** — 策略指引 < 模板框架 < 程序脚本（ch08）。
- **失败优先** — 先让智能体裸跑，把失败点变成需求清单（ch06）。
- **负向条件** — 明确"何时不要用本 Skill"，用于易混淆场景（ch06）。

## G
- **感知-规划-行动** — 智能体四大组件（大模型/规划/记忆/工具）的协作方式（ch01、ch03）。
- **工具调用** — 模型输出调用标记、宿主程序拦截执行的机制（ch01）。
- **规则外置** — 把筛选规则等放 references，实现多场景复用（ch09）。

## J
- **渐进式披露** — 元数据→正文→资源，三级按需加载（ch02）。
- **检查清单** — 执行中逐项打钩，最后核对是否完成（ch06）。
- **脚本自愈安装** — 让智能体按报错自动安装依赖（ch08）。
- **可移植性** — 自包含 + 相对路径 + 纯文本带来的跨平台能力（ch02）。

## L
- **两阶段 Skill** — 学习阶段产出规范与脚本，使用阶段反复执行（ch09 公文）。
- **任务四要素** — 描述精准、流程清晰、边界明确、格式规范（ch02）。

## M
- **MCP** — 模型与外部工具/数据的标准连接协议（AI 的 USB）（ch01、ch08）。
- **模板框架** — 三级约束中间级：固定输出结构，内容自填（ch08）。
- **裸跑（Baseline Run）** — 不带 Skill 先做一遍，观察失败（ch06）。

## P
- **评估用例** — 输入场景 + 期望标准的"考题"，不写进 Skill（ch06）。

## Q
- **前置条件（compatibility）** — 元数据中声明环境要求（ch02）。
- **纯文本优先** — references 首选 .md/.txt，减少解析成本（ch07）。

## R
- **references** — 供"阅读理解"的知识库目录（ch02、ch07）。
- **任务拆分** — 把需求拆成读取/理解/判断/输出几段再选约束级别（ch09）。

## S
- **SKILL.md** — Skill 唯一必需文件，含 YAML 元数据 + Markdown 正文（ch02）。
- **scripts** — 供执行的代码目录（ch02、ch08）。
- **四件套** — SKILL.md + references + scripts + assets（ch02）。
- **上下文外处理** — 用脚本/子智能体承接重活，只把结论搬进上下文（ch06）。
- **三档分类** — 确定淘汰/确定通过/待人工审查（ch09）。

## T
- **提示词框架** — 人设+背景+目标+细节+例子（ch01）。
- **图示（渐进式披露层级）** — 元数据层/指令层/资源层（ch02）。

## W
- **文件名即索引** — 用长而清晰的文件名替代内部索引（ch07）。
- **五标准** — 元数据准、边界清、输入输出明、步骤可执行、失败处理全（ch06）。

## X
- **上下文窗口** — 智能体的"工作台"，决定能装多少、能记多久（ch02、ch03）。
- **显性知识 / 隐性知识** — 可写手册的 vs 藏在直觉里的（ch05）。
- **项目级 / 全局级 / 组织级** — Skill 的三层作用域与优先级（ch02、ch04、ch12）。
- **信任分级** — 完全信任/基本信任/谨慎/不用（ch03）。

## Y
- **元数据（Metadata）** — name/description 及可选的 license/compatibility/metadata（ch02）。
- **一次编写多处运行** — OpenSkills 标准带来的跨工具复用（ch04）。

## Z
- **智能体（Agent）** — 给目标即可自主规划执行的 AI 实体（ch01）。
- **子智能体** — 独立上下文、只回传结果的执行单元（ch03、ch06）。
- **资产（assets）** — 模板、Logo、样式等"直接使用"的素材（ch02）。
- **索引.md** — 知识库的目录卡片（ch07）。
