# 第 10 章：内容写作案例

## 核心思想
内容类 Skill 的价值不在"生成文字"，而在**把爆款的结构拆出来，再把你的内容填进去**。三个案例分别对应内容生产链的三段：选题（找什么写）、写作与排版（怎么写）、音视频（怎么呈现）。

## 本章框架

- **10.1 自媒体自动选题**
  - 任务拆分：热点抓取（工具/MCP）→ 相关性过滤（策略指引）→ 选题评分（模板/规则）→ 输出选题清单。
  - 关键：选题标准要显性化（受众匹配度、时效性、竞争度、可写性），否则模型只会给"泛泛的热点"。
- **10.2 公众号写作与自动排版**
  - 三段式：内容生成（策略指引，给风格与结构，不给逐句模板）→ 结构套用（模板：开头钩子/分段/金句/CTA）→ 排版渲染（脚本：Markdown/HTML → 样式化输出）。
  - 关键：**风格用样例约束**（few-shot 优于形容词），排版用脚本保证一致性。
- **10.3 自媒体视频播客制作**
  - 链路：选题→脚本→配音/字幕（脚本+API）→ 剪辑参数→发布文案。
  - 关键：把"重活"（转写、切片、格式转换）全部交给脚本，模型只做判断与创作。
- **三条通用规律**：
  1. 创作环节用**策略指引**（保留灵活性），产出环节用**模板**（保证一致性），处理环节用**脚本**（保证准确）；
  2. 风格靠**样例**而非描述；
  3. 一条内容流水线 = 多个单一职责 Skill 的编排。

## 关键概念
- **爆款结构**：钩子—冲突—展开—反转—行动号召的可复用骨架。
- **样例约束**：用 2–3 篇范文替代抽象的风格形容词。
- **流水线编排**：选题 Skill → 写作 Skill → 排版 Skill → 发布 Skill。

## 心智模型
- **"仿结构，不仿内容"**：结构可迁移，内容必须原创。
- **"创作交给模型，一致性交给模板"**：两者混用会两头不讨好。
- **"内容工厂的瓶颈在选题与审稿，不在写作"**：所以选题 Skill 的 ROI 最高。

## 反模式
- 用一段提示词让 AI"写得像我"（没有样例，必然跑偏）。
- 把排版交给模型（每次格式都不一样）。
- 一个 Skill 包办选题到发布（无法迭代单点）。

## 关键结论
1. 内容类 Skill 的竞争力在于"风格样例库 + 结构模板"，不在提示词技巧。
2. 越是创意环节，越要少约束；越是交付环节，越要多约束。
3. 拆成流水线，才能定位"哪一段拖后腿"。
