# 第 1 章：AI 的进化阶梯

## 核心思想
AI 的能力是**层层叠加**的五级阶梯：提示词解决"怎么说"，工具调用解决"能不能做"，MCP 解决"怎么统一连接"，智能体解决"能不能自己干"，Skill 解决"能不能干得专业"。多数人卡在第一级，所以觉得 AI"能聊天但没法干活"。

## 本章框架

- **五级阶梯**：
  1. **提示词（Prompt）**：一次性的指令。框架＝立人设（Role）+ 给背景（Context）+ 定目标（Task）+ 补细节（Constraints）+ 举例子（Few-shot）。
     - 三个局限：一次性、不稳定、被动。
  2. **工具调用（Tool Calling）**：模型只输出文本，由宿主程序"截和"执行。流程＝定义暗号规范 → 用户提问 → AI 输出调用标记 → 系统拦截并执行 → 结果回填 → AI 最终回答。
     - 解决三件事：连接现实（突破知识截止）、精确计算、执行操作。
  3. **MCP**：统一"模型↔工具/数据"的连接标准（AI 时代的 USB）。解决 N×M 重复适配。
  4. **智能体（Agent）**：给目标而非指令，自主"感知—规划—行动—反思"。
     - 四大组件：大模型、规划、记忆、工具。
     - 三个问题：不稳定与幻觉、缺私有知识、博而不精。
  5. **Skill**：把专业知识、流程、最佳实践封装成"标准作业手册"，解决上面三个问题。
- **为什么是 Skill**：它同时提供**约束**（流程稳定）、**私有知识**（references）、**专精**（单一职责）。
- **复用经济学**：花 2 小时写一个 Skill，可能省下 200 小时的重复解释；且可跨人、跨工具、跨组织复用。
- **五者协同（竞品分析案例）**：提示词打底 → 工具调用取实时数据 → MCP 接内部库 → 智能体自主规划 → Skill 保证分析框架与输出格式。

## 关键概念
- **提示词工程**：优化指令的过程，但受限于一次性与不稳定。
- **缸中之脑**：大模型被知识截止日期困住，无法感知当下。
- **数字员工**：能自主完成岗位工作的 AI 实体；Skill 是它的岗位手册。
- **Skill 市场**：像应用商店一样分发专业能力的形态。

## 心智模型
- **"能力靠叠加，不靠替换"**：五级不是迭代淘汰，而是同时在场、各司其职。
- **"越重复、越专业、越要求稳定，越值得做成 Skill"**：这是判断要不要写 Skill 的第一原则。
- **"给目标 vs 给步骤"**：智能体吃目标，脚本吃步骤，Skill 规定"什么情况下用哪种"。

## 反模式
- 用提示词硬扛需要稳定输出的重复任务（每次结果都不一样）。
- 以为接上工具就等于有了智能体（缺规划与记忆）。
- 把 MCP 当银弹（它只统一连接，不提供专业知识与流程）。

## 关键结论
1. 判断需求该用什么：一次性 → 提示词；要实时/操作 → 工具；多服务 → MCP；多步自主 → 智能体；专业+稳定+重复 → Skill。
2. Skill 是"站在前四者肩膀上"的集大成者，不是替代品。
3. 专业知识的稀缺性才是价值来源——Skill 把专家经验变成可传递资产。
