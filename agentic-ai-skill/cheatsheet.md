# 速查表：决策规则与阈值

## 决策规则（当 X，做 Y，因为 Z）

| 当… | 做… | 因为… |
|---|---|---|
| 想上 Agent | 先过"四问"筛查 | 简单任务上 Agent 是负优化（ch05） |
| 流程还没标准化 | 先做流程梳理/挖掘，再谈 Agent | 会把混乱自动化（ch06） |
| 团队分不清 Agentic AI/AI Agent/Workflow | 用三层级模型对齐 | 概念混用是讨论跑偏的根源（ch01） |
| 只有单 Agent 跑不动跨系统任务 | 引入编排/多 Agent | 单点能力有上限（ch05） |
| 多 Agent 意见冲突 | 设仲裁规则（风险>合规>成本） | 否则协作变甩锅（ch12） |
| 要扩到多部门 | 先立治理（原则+委员会+闸门） | 无治理的规模化会被一次事故终止（ch12） |
| 成本敏感的高频问答 | 大小模型分工（70/30） | 全量大模型不经济（ch07） |
| 高风险决策（赔付/诊断/授信） | HITL，保留人工签字 | 责任无法交给模型（ch11） |
| 上线后准确率下滑 | 查知识库老化与分布漂移 | 无维护的 Agent 三个月就衰变（ch07） |
| 业务不采纳 | 改考核/权限/岗位描述 | 只培训无效（ch08） |
| 要报 ROI | 先建基线，再算增量 | 无基线无法归因（ch06） |
| 选型供应商 | 用五维评估 + POC 场景测试 | 厂商口径不可直接采信（ch06） |

## 阈值与数字（书中锚点）

- **CUA 基准**：OSWorld 成功率 38.1% vs 人类 >70% → "能演示"≠"能生产"（ch11）。
- **企业软件渗透**：2028 年 33% 集成 Agentic AI，2024 年不足 1%（ch13）。
- **决策自动化**：2028 年 15% 日常决策由 Agent 自主完成（ch02、ch13）。
- **项目存活率**：到 2027 年超 40% Agentic AI 项目可能中止；合规供应商不足 130 家（ch02）。
- **成功配比**：技术 20% / 变革管理 80%（ch03）。
- **客服分流**：70% 常见问题走 NLP、30% 复杂走 Agent（ch07）。
- **财务案例**：错误率 2–5% → <0.1%；单据处理效率 +95%；团队 8 人 → 2 人 + 100 个 Agent（ch07）。
- **制造案例**：工艺调参周期 −90%、节拍 +7%、能耗 −10%（ch07）。

## 识别信号（看到这些，说明你在错误的路上）

- 需求写的是"我们要一个 AI 助手" → 无法验收（ch11）。
- KPI 只有"自动化率"，没有"接管率" → 可能只是把人工判断改成人工复核（ch06）。
- 汇报只有 demo 视频，没有 1000 条样本的分布指标 → 没做验收（ch12）。
- "多 Agent"是卖点但画不出协作协议 → 大概率是 5 个 Agent 互相等待（ch05）。
- 没有日志/追踪 → 无治理、无优化、无审计（ch12）。
- 用"未来能力"做今天的承诺 → 销售话术（ch13）。

## 一句话判据

> **Agent 的价值 = 闭环完成率 × 单次决策价值 ÷（接管成本 + 风险敞口）。**
