# 模式库（可操作的方法）

## 1. 场景筛查四问
**何时用**：任何"要不要上 Agent"的判断。
**怎么做**：① 任务是否复杂到需适应性决策？② 更简单的 AI（纯 RAG/规则）能否达到同样结果？③ 是否存在不确定性、条件变化、多步推理？④ 授予自主性的风险能否缓解？
**权衡**：四问会否掉一半项目——这正是它的价值；但会漏掉"流程本身就该重构"的机会。

## 2. 三级阶梯定位
**何时用**：制定 AI 战略、申报预算。
**怎么做**：先判断当前处于自动化优先/AI 优先/Agentic 优先哪一级；按"下一级"配置资源，不跳级。
**权衡**：稳健但慢；激进跳级在数据与系统接口齐备的企业可行，否则返工。

## 3. 目标驱动流程设计
**何时用**：重构审批、客服、供应链等规则复杂的流程。
**怎么做**：把"步骤说明"改为"目标 + 约束 + 可用工具 + 成功判据"，让 Agent 自行规划；人类保留终审。
**权衡**：灵活性与可预测性互换；需要更强的可观测性与护栏。

## 4. 大小模型分工
**何时用**：高频客服/问答类场景，成本敏感。
**怎么做**：70% 常见问题走 NLP/小模型，30% 复杂问题走 Agent/大模型；按命中率动态调比例。
**权衡**：显著降本；但路由错误会让简单问题变复杂，需监控错分率。

## 5. 四大设计模式组合
**何时用**：设计 Agentic Workflow。
**怎么做**：确定性高 → 规划 + 工具（ReWOO 式先规划后执行）；质量要求高 → 反思迭代；跨系统 → 多 Agent 协作；不确定 → ReAct 边做边调。
**权衡**：反思最贵，多 Agent 最难调；组合越多，可观测性要求越高。

## 6. 由 RPA 渐进到自主
**何时用**：已有 RPA/自动化基础的企业。
**怎么做**：基础自动化 → 增强（OCR/NLP）→ 集成智能（端到端 + 决策）→ 自主智能 → 生态级；每阶段积累数据与信任。
**权衡**：周期长；但跳过中间阶段通常卡在"数据不通 + 责任不清"。

## 7. 治理先于规模化
**何时用**：准备从试点扩到多部门。
**怎么做**：先立九原则 + 指导委员会 + 八项机制（立项/闸门/风险/变更/数据/合规/度量/复盘），再放量。
**权衡**：治理有开销；无治理的规模化会在第一次事故后全面停摆。

## 8. 可观测性三件套
**何时用**：任何生产环境的 Agent。
**怎么做**：日志（提示/响应/工具调用）+ 分布式追踪 + 指标（成功率/步数/成本/接管率）；"无日志=无治理"。
**权衡**：存储与隐私成本；但缺日志时，优化与审计都无从谈起。

## 9. 冲突仲裁机制
**何时用**：多 Agent 给出矛盾建议。
**怎么做**：定义优先级（风险 > 合规 > 成本）、置信度阈值、升级路径（转人工裁决）。
**权衡**：仲裁规则本身可能成为瓶颈；需要定期复盘仲裁结果。

## 10. 数字员工"转正"考核
**何时用**：把 Agent 纳入正式岗位。
**怎么做**：设试用期指标（准确率、完备率、接管率、满意度），达标转正；不达标回炉或下线。
**权衡**：管理清晰、易向业务解释；但指标设计不当会诱导 Agent"只答会的"。

## 11. 数据飞轮
**何时用**：希望 Agent 越用越准。
**怎么做**：交互 → 标注/纠错 → 写入长期记忆或微调 → 检索增强 → 再交互；配质量抽检防污染。
**权衡**：复利明显；但记忆投毒与偏见固化风险同步上升。

## 12. 变革管理三件套
**何时用**：Agent 上线但采纳率低。
**怎么做**：改考核（用不用 AI 进绩效）+ 改权限（真的把任务交出去）+ 改岗位描述（人机分工写清楚）。
**权衡**：动到利益，阻力最大；只做培训不改这三样，基本无效。
