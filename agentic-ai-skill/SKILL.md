## 核心框架与心智模型

**1. 三者层级（全书最重要的概念清理）**
| 概念 | 定位 | 关注点 |
|---|---|---|
| Agentic AI | 顶层：理念/系统/战略 | 自主性的原理与方法 |
| AI Agent | 中层：执行单元 | 单体/多体的设计与行为 |
| Agentic Workflow | 底层：流程蓝图 | 如何编排 Agent 完成业务 |
类比：前者是"造机器人的科学"，中者是"那台机器人"，后者是"它做事的步骤"。

**2. 定义与九特征（ch01）**
Agentic AI＝能自主决策、动态适应、持续行动以完成复杂目标的范式。
- 核心 5：自主性、目标导向、适应性、学习与自我优化、实时复杂决策；
- 扩展 4：环境感知、任务协调与灵活性、多 Agent 协作、主动性。
- 区分：**自主性**＝不需干预即可运作；**主动性**＝主动识别机会/风险。

**3. 运行闭环与架构（ch03）**
感知 → 推理 → 行动 → 学习；LLM 三角色＝推理引擎 / 工具选择器 / 响应合成器。
- 五组件：感知、认知、**记忆**、行动、学习（记忆单列，因为它是跨轮一致性的唯一载体）。
- 六层：协调控制 / 感知 / 推理规划 / 记忆 / 执行 / 输出。

**4. 四大设计模式（吴恩达框架，ch05）**
规划、工具使用、反思、多 Agent 协作；衍生：自适应、记忆管理、任务协调、并行。
- 选型：确定性高 → 先规划后执行（ReWOO 式，省 token）；不确定高 → ReAct（能纠偏）；质量要求高 → 反思（贵但准）。

**5. 场景筛查四问（ch05，最实用的前置过滤器）**
① 是否复杂到需适应性决策？② 更简单的 AI（纯 RAG/规则）能否达到？③ 是否存在不确定性/多步推理？④ 授予自主性的风险能否缓解？
四问会否掉约一半项目——这是它的价值。

**6. 三级战略阶梯（ch09）**
自动化优先（RPA/规则）→ AI 优先（ML/NLP/预测）→ Agentic AI 优先（LLM+规划+工具+记忆）。
递进而非替代：没有自动化基础，Agent 调不动系统；没有 AI 能力，Agent 没有大脑。

**7. 成熟度与阶段（ch06、ch10）**
- PAMM：0/1 初始 → 2 可重复 → 3 已定义 → 4 已优化 → 5 智能自主；
- 五阶段路径：基础自动化 → 增强 → 集成智能 → **自主智能** → 生态级；
- 作者 L0–L4：探索实验 → 单点辅助 → 流程自动化协作 → 跨职能自主 → 全企业智能（五维：战略治理/数据基建/技术开发/应用价值/人才文化）。

**8. 落地与治理（ch06、ch11、ch12）**
- BPR 八理念：目标驱动、决策点授权、端到端整合、自适应优化、多 Agent 编排、人机协同、仿真探索、知识注入；
- 评估五维：业务价值（TCO/ROI）、运营效率（延迟/周期/接管率）、Agent 性能（成功率/自主决策比例）、体验（CSAT/NPS）、技术影响（稳定性/安全/集成）；
- 治理九原则 + 八机制（立项/闸门/风险/变更/数据/合规/度量/复盘）；**无日志 = 无治理**。

**9. 风险清单（ch11）**
记忆投毒、工具滥用、权限泄露、资源过载、级联幻觉、意图破坏、错位欺骗、不可追溯、身份冒充、告警淹没、对抗性 ML、Agent 间串通、法律责任。
- 现状锚点：CUA 在 OSWorld 仅 38.1%，人类 >70% → "能演示"≠"能生产"。

**10. 两个清醒的数字（ch02）**
Gartner：2028 年 15% 日常决策由 Agent 自主完成；但到 2027 年**超 40% 的 Agentic AI 项目可能中止**。热度与死亡率同时为真。

## 范围与限制

本书出版于 **2026 年 1 月**，信息截止约 2025 年底，是本领域"快照型"著作。使用时注意三点：

1. **预测与厂商口径多**：书中市场规模、CAGR、"减少 50% 工作量/99.9% 准确率"等多为咨询机构预测或供应商自述，未经独立验证，引用时务必标注来源与口径。
2. **框架未收敛**：成熟度模型至少五套并存（PAMM、Salesforce、MIT CISR、作者 L0–L4、theCUBE 六阶梯），说明领域尚无共识——本书的价值是"清单齐全"，不是"标准答案"。
3. **图文缺失**：EPUB 纯文本提取丢失了 75 张图表；本技能基于正文重构，未包含原图。

本书的立场是"拥抱 + 理性"：认为 Agent 是"人类能力的外骨骼"而非替代。评估其判断时，建议与 Gartner 的 40% 中止率、CUA 38.1% 成功率并置阅读。
