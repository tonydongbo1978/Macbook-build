# 第 10 章：用 Agentic AI 构建竞争优势

## 核心思想
竞争优势不来自"用了 Agent"，而来自**能力沉淀**：成熟度、数据资产、生态位、以及把技术转化为组织能力的速度。作者给了一个五级模型（L0–L4）作为自评与路线工具。

## 本章框架

- **AI 能力成熟度（多模型并存）**：
  - Gartner 五阶段：规划、实验、稳定、扩张、转化（七领域：战略/产品/治理/工程/数据/运营模式/文化）；
  - Salesforce Agentic AI 成熟度：五层，面向 CIO；
  - MIT CISR：四阶段（含分析型/生成型/Agent 型/机器人型），阶段 3–4 的财务表现显著优于行业；
  - **作者的五级模型（L0–L4）**：探索与实验 → 单点应用与辅助 → 流程自动化与协作 → 跨职能自主与优化 → 全企业智能与变革。
    - 五个维度：战略与治理、数据与基础设施、技术与开发、应用与价值、人才与文化。
    - Agentic 能力在 L2 萌芽、L3 成熟、L4 领先。
- **数据战略与治理**：数据战略（资产化、分级分类、实时化）→ 治理（质量、安全、合规、血缘、权限）→ 面向 Agent 的特殊要求（工具可读、上下文可用、检索可靠）。
- **生态系统协同**：以 Agent 为接口连接供应商/渠道/客户（B2A 市场），共享智能服务，形成"跨组织流程"。
- **战略创新**：用 Agent 做市场发现、方案生成、模拟推演；从"降本"走向"新业务/新模式"（如保险从赔付转向风险管家）。

## 关键概念
- **数据资产化**：数据可计量、可复用、可交易，才有战略价值。
- **B2A（Business-to-Agent）**：企业服务 Agent 而非人类用户的接口模式。
- **能力成熟度 ≠ 技术成熟度**：前者包含治理、人才、文化，后者只有模型与工具。

## 心智模型
- **"优势 = 难以复制的组合"**：模型可买、框架开源，难复制的是"数据 + 流程 + 组织习惯"。
- **"成熟度决定杠杆点"**：L1 的杠杆是场景选择，L3 的杠杆是编排与治理，L4 的杠杆是生态。
- **"先做深一个域，再做宽"**：跨职能自主（L3）必须建立在一个域的端到端跑通之上。

## 反模式
- 用"模型参数/榜单排名"当竞争优势（会迅速商品化）。
- 数据治理滞后于 Agent 上线（垃圾进、决策出）。
- 生态合作只签框架协议，不做接口与责任约定。

## 关键结论
1. 竞争优势的时间窗口在"组织学习速度"，不在"技术领先幅度"。
2. 数据治理是 Agent 规模化的前置条件，不是配套工程。
3. 生态协同的收益与风险同源：连接越多，攻击面与责任边界越复杂。
