# 第 2 章：市场现状与竞争格局

## 核心思想
Agentic AI 已从概念进入"平台卡位 + 商业模式试验"阶段：巨头拼全栈与生态（模型—框架—协议—应用），创业公司拼垂直与集成，而商业模式正从"卖软件"转向**卖结果**（按成果付费、决策即服务）。

## 本章框架

- **市场规模口径（书中引用的多组预测，注意互相不一致）**：
  - 中国 AI Agent 软件市场：2024 年 500 亿元 → 2028 年 8520 亿元，CAGR 72.7%；
  - 全球：2025 年 138 亿美元 → 2032 年 1408 亿美元（39.3%）／2024 年 54 亿 → 2030 年 503 亿（45.1%）；
  - Gartner：2025 十大战略技术趋势之首；2028 年 15% 日常决策由 Agent 自主完成、33% 企业软件集成 Agentic AI；
  - Gartner（冷水）：到 2027 年**超 40% 的 Agentic AI 项目可能中止**（成本、价值不明、风险失控），真正符合标准的供应商不足 130 家。
- **巨头布局的四种打法**：
  1. **全栈 + 协议**（微软：Semantic Kernel/AutoGen、Azure AI Foundry、MCP/A2A、Entra Agent ID）；
  2. **模型 + 生态**（谷歌 Gemini、Vertex AI Agent Builder、A2A 协议、Project Astra）；
  3. **智能体即服务**（亚马逊 Bedrock/AgentCore/Strands、Nova）；
  4. **场景纵深**（阿里 Qoder、腾讯"1+3+N"、华为"云管端"、字节豆包/Coze、京东 1.4 万内部智能体）。
- **20 种商业模式（两大类）**：
  - **核心服务模式 4 种**：订阅制、按使用付费、**按成果付费**（Outcome-based）、免费增值。
  - **平台与生态模式 16 种**：平台/Agent 商店、MaaS、AaaS、垂直行业方案、集成服务、咨询托管、技术许可/OEM、数据与分析服务、RaaS（机器人即服务）、**决策即服务**、B2C 消费者服务、自主管理（私有化）、深度自动化、超个性化、创新加速等。
- **投资六大热点**：基础模型与核心技术、Agent 开发框架与平台、垂直行业应用、通用任务型 Agent、多 Agent 系统、Agent 安全与伦理。

## 关键概念
- **按成果付费**：把服务商与客户利益绑定，但"成果界定"极难，易生纠纷。
- **决策即服务**：直接输出批准/拒绝、买入/卖出等决策，价值最高、责任最重。
- **Agent Store**：智能体应用商店，平台抽成，长尾供给，质量控制是命门。
- **A2A / MCP**：前者解决 Agent 间协作（AgentCard 描述能力），后者解决模型与工具/资源的标准化连接。

## 心智模型
- **"价值主张越靠后，定价越贵"**：算力 < 模型 < Agent < 流程 < 决策。定价能力随"承担的责任"上升。
- **"生态位决定毛利"**：做平台赚网络效应的钱，做垂直赚行业 know-how 的钱，做集成赚交付的钱——三者能力要求完全不同。
- **"预测要以口径为单位打折"**：同一市场有 39% 与 45% 两个 CAGR、有 500 亿与 54 亿两个起点，说明统计口径未统一；引用时必须带口径。

## 反模式
- 用 TAM 预测替代客户付费意愿（"万亿市场"不等于有人买单）。
- 只做通用 Agent 而没有分发渠道（被平台吞掉）。
- 按"降本比例"卖，却不锁定基线（客户会质疑节省归因）。

## 关键结论
1. 市场热与落地冷同时为真：融资与发布极热，Gartner 却给出 40% 中止率——**立项要多，投产要少**。
2. 商业模式的重心正从"席位"转向"用量"再转向"结果"，每一次转移都要求更强的可度量性。
3. 巨头的护城河是协议 + 分发，创业公司的护城河是行业数据 + 交付能力。
