# 第 4 章：AI Agent 深度解析

## 核心思想
一个 Agent 的智能由四件事决定：**感知到什么、怎么推理、记得什么、怎么协作**。其中"决策机制"是它区别于自动化程序的根本——它能在不确定环境里选择"下一步做什么"。

## 本章框架

- **感知四步**：数据采集 → 数据处理（特征提取）→ 模式识别 → 决策输入。
  - 感知类型：视觉、听觉、文本、环境（多传感器融合）、预测性感知。
  - Agent 分级（按感知依赖）：简单反射型 → 基于模型的反射型 → 目标导向型 → 效用导向型。
- **推理机制四类**：逻辑推理（演绎/归纳/溯因）、效用推理（最大化期望效用）、目标导向推理（A*/STRIPS 规划）、学习推理（RL/监督）。
  - 高级框架：**ReAct**（思考—行动—观察循环，动态调整）、**ReWOO**（先规划后执行，减少工具依赖与 token 消耗）。
  - 推理三步：数据整合 → 假设生成 → 验证优化。
- **决策机制四组件**：目标与效用函数 / 感知与信息处理 / 推理与规划器 / 学习与反馈适配。
  - 决策循环：感知输入 → 推理处理 → 决策输出 → 行动执行 → 反馈循环。
- **知识表示七种**：逻辑、产生式规则、语义网络/框架、本体、向量嵌入、知识图谱、记忆模块。
  - LLM 的角色：隐式知识库 + 自然语言接口 + RAG 外挂 + 推理引擎 + 工具调用 + 记忆管理。
- **记忆四类型**：短期（上下文窗口）、长期（向量库/RAG）、**情景记忆**（特定事件+时间地点）、**语义记忆**（一般知识与概念）。
  - 检索策略：重要性评分、相关性（向量检索）、近期性权重；用摘要压缩长对话。
- **学习三路径**：预训练/微调（离线）、在线持续学习（RL/RLHF）、**通过记忆更新实现"学习"**（把用户纠正写入长期记忆，再用 RAG 引导后续回答）——这是 LLM Agent 最实用的一条。
- **编排与调度**：
  - 原则：模块化、松耦合、可扩展、动态适应、目标一致、职责清晰、容错、可监控、上下文感知；
  - 任务分配 10 种：集中/分布、静态/动态、基于能力/优先级/市场/合约网/角色、分散式协商；
  - 异常处理流程：检测 → 诊断 → 隔离 → 恢复与重分配（重试/转派/重启/降级）→ 日志 → 报告 → 告警 → 自我修复。
- **通信协议**：FIPA-ACL（事实标准，言语行为）、KQML（知识查询）、**A2A**（Google 2025，AgentCard + 任务生命周期）、**MCP**（Anthropic，JSON-RPC 2.0，工具与资源标准化）、CNP（合同网，任务招标）。
  - 分层：语法层 / 语义层（内容语言+本体+言语行为）/ 语用层（交互协议）。

## 关键概念
- **效用函数**：把"好坏"量化为可比较的分数，是自主决策的前提。
- **AgentCard**：A2A 中用 JSON 描述 Agent 能力与认证方式的元数据。
- **记忆投毒**：通过污染记忆/训练数据改变 Agent 长期行为（第 11 章安全风险）。
- **级联幻觉**：错误在多轮、多 Agent 间累积放大。

## 心智模型
- **"Agent = 目标 + 工具 + 记忆 + 反馈"**：缺任一项，它只是"会说话的脚本"。
- **"先规划后执行 vs 边做边想"**：确定性高的任务用 ReWOO（省成本），不确定性高的用 ReAct（能纠偏）。
- **"记忆分层 = 成本分层"**：短期记忆贵在上下文窗口，长期记忆贵在检索质量。

## 反模式
- 用单 Agent 硬扛多角色任务（应拆分为 MAS）。
- 无异常处理：一个工具 500 错误就让整个流程死掉。
- 让 Agent 在无协议、无身份校验的情况下互相调用（A2A/MCP 的安全前提被忽略）。

## 关键结论
1. 评估 Agent 要看四个指标：任务成功率、平均步数、人工接管率、单任务成本。
2. 多 Agent 的收益来自"分工降低单点复杂度"，代价是"通信与协调成本"——超过 5–7 个角色通常得不偿失。
3. 协议标准化（MCP/A2A）是互操作的前提，但也是新的攻击面。
