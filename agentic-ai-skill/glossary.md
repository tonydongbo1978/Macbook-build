# 术语表（按拼音首字母分组）

## A
- **A2A** — Google 2025 年提出的 Agent 间协作协议，用 AgentCard 描述能力，支持任务状态管理与安全协作（ch04）。
- **AaaS（Agent-as-a-Service）** — 把预构建的端到端 Agent 作为服务交付，客户买"解决问题的能力"（ch02）。
- **ABMS** — 基于 Agent 的建模与仿真，上线前在虚拟环境测试流程设计（ch06）。
- **Agentic AI** — 能自主决策、动态适应、持续行动以实现复杂目标的 AI 范式（技术+系统+战略）（ch01）。
- **Agenticness** — 系统的"智能性/能动性"程度，含目标复杂性、环境复杂性、适应性、独立执行四维（ch01）。
- **Agentic RAG** — 由 Agent 规划检索（分解查询、多源检索、反思补检）的 RAG（ch05）。

## C
- **CoE（卓越中心）** — 统一自动化/AI 标准、复用组件、集中治理的组织单元（ch06、ch12）。
- **CNP（合同网协议）** — 管理者发布任务、执行者投标的任务分配协议（ch04）。
- **场景组合管理** — 70% 确定能赢 / 20% 可复制 / 10% 探索的资源分配法（ch09）。

## D
- **大小模型融合** — 简单问题走小模型/规则控成本，复杂问题走大模型/Agent 保质量（ch07）。
- **动态决策** — 由 LLM 按目标自主分解任务、选择工具，而非执行预设路径（ch13）。
- **多智能体系统（MAS）** — 多个角色化 Agent 分工协作完成复杂任务（ch04）。

## F
- **分级 HITL/HOTL** — 人在回路（关键点介入）与人在回路之上（监控异常）按风险选择（ch11、ch12）。

## G
- **感知—推理—行动—学习闭环** — Agentic AI 的运行主干（ch03）。
- **功能调用（Function Calling）** — 模型决策→工具执行→结果回流的机制（ch03）。
- **规程/护栏（Guardrail）** — 限制 Agent 行为边界的可执行约束，如金额上限、工具白名单（ch03、ch11）。

## J
- **记忆分层** — 短期（上下文窗口）/长期（向量库）/情景（具体事件）/语义（一般知识）（ch04）。
- **级联幻觉** — 错误在多轮、多 Agent 间累积放大（ch04、ch11）。
- **决策即服务** — 直接输出批准/拒绝、买卖建议等决策并收费（ch02）。
- **九大特征** — 自主性、目标导向、适应性、学习与自我优化、实时复杂决策（核心）；环境感知、任务协调、多 Agent 协作、主动性（扩展）（ch01）。

## L
- **流程拥有者** — Agent 端到端接管整个流程（而非单任务）的角色形态（ch13）。
- **流程挖掘** — 用系统日志还原真实流程、识别瓶颈（ch06）。
- **六层架构** — 协调控制 / 感知 / 推理规划 / 记忆 / 执行 / 输出（ch03）。

## M
- **MCP** — Anthropic 的模型—工具连接标准，JSON-RPC 2.0，标准化工具发现与资源访问（ch04）。
- **Agentic AI 之梯** — theCUBE 的六级路线：微调→领域知识→决策智能→智能主体→协作→实时学习（ch11）。
- **模式库（设计模式）** — 规划、工具使用、反思、多 Agent 协作四大模式（ch05）。

## R
- **RaaS（结果/机器人即服务）** — 按业务成果收费，或按需租用机器人能力（ch02、ch13）。
- **任务分配十法** — 集中/分布、静态/动态、能力/优先级/市场/合约网/角色、分散式协商（ch04）。
- **人在回路** — 关键节点人工审批，兼顾自主与可控（ch05）。

## S
- **三级战略阶梯** — 自动化优先 → AI 优先 → Agentic AI 优先，递进而非替代（ch09）。
- **三大转变** — 任务自动化→流程拥有者；单 Agent→多 Agent 团队；人机交互→自主运营（ch13）。
- **数字化能力评估** — 从战略/数据/技术/流程/人才/文化六维定位差距（ch08）。

## T
- **PAMM（流程自动化成熟度模型）** — 0/1 初始 → 2 可重复 → 3 已定义 → 4 已优化 → 5 智能自主（ch06）。
- **五阶段路径** — 基础自动化→增强→集成智能→自主智能→生态级智能（ch06）。
- **L0–L4 模型** — 作者的 AI 能力成熟度：探索实验→单点辅助→流程自动化协作→跨职能自主→全企业智能（ch10）。

## W
- **五组件** — 感知、认知、记忆、行动、学习（ch03）。
- **Agent 五类** — 简单反射、基于模型、目标导向、效用导向、学习型（ch04）。
- **提示词模板库** — 独立可配置、可单独调优的提示词仓库（ch05）。

## X
- **效用函数** — 把行动结果量化为可比较分数，是自主决策的前提（ch04）。
- **消息投毒/记忆投毒** — 污染训练数据或记忆，改变 Agent 长期行为（ch11）。
- **协议三层** — 语法 / 语义（内容语言+本体+言语行为）/ 语用（交互协议）（ch04）。

## Y
- **越权与工具滥用** — 通过欺骗性提示让 Agent 调用不该调用的工具（ch11）。
- **业务价值五维** — 业务价值、运营效率、Agent 性能、用户体验、技术影响（ch06）。
- **意图破坏** — 攻击者通过提示或工具输入劫持 Agent 的目标（ch11）。

## Z
- **智能体即服务** — 见 AaaS。
- **自主决策比例** — 真正由 Agent 做出的决策占比，自主性的硬指标（ch06）。
- **知识表示七法** — 逻辑、产生式、语义网络、本体、向量嵌入、知识图谱、记忆模块（ch04）。
- **治理九原则** — 战略对齐、价值驱动、风险可控、责任明确、透明公开、伦理优先、合规守法、持续学习、以人为本（ch12）。
