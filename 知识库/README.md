## 定期机制

### 📰 时事速递（IT 领域）

每日跟踪 IT 重大事件，月末自动汇总。详见 [机制说明](01-IT知识/时事速递/README.md)。

```bash
python3 知识库/scripts/new_digest.py           # 新建当天日报（基于模板）
python3 知识库/scripts/monthly_digest.py       # 生成当月汇总
python3 知识库/scripts/monthly_digest.py 2026-10   # 指定月份
```

| 产物 | 路径 |
|---|---|
| 每日日报 | `01-IT知识/时事速递/IT重大事件-YYYY-MM-DD.md` |
| 月度汇总 | `01-IT知识/时事速递/月度汇总/月度汇总-YYYY-MM.md` |
| 模板 | `01-IT知识/时事速递/_模板.md` |

**定时任务**：已配置 launchd `com.local.kb-digest`，每日 **07:00** 自动生成草稿。
详见 [定时任务说明](scripts/定时任务说明.md)。

```bash
launchctl print gui/$(id -u)/com.local.kb-digest          # 查看状态
launchctl kickstart -p gui/$(id -u)/com.local.kb-digest   # 立即触发
bash 知识库/scripts/daily_digest.sh                        # 手动执行（最可靠）
```

> ⚠️ 定时任务已注册但受 DSH 沙箱限制无法实际执行，需在普通终端重新加载。详见说明文档。

## 使用约定

1. **一主题一文件**：单个知识点独立成文，文件名即标题（例：`Git-常用命令速查.md`）。
2. **命名规范**：`主题-子主题.md`，用中文或英文均可，避免空格与特殊符号。
3. **文首元信息**：每篇笔记建议以如下格式开头，便于检索与生成索引。

   ```markdown
   ---
   分类: 01-IT知识
   标签: [linux, 网络]
   创建: 2026-10-13
   更新: 2026-10-13
   ---
   ```

4. **收件箱机制**：暂时不确定归类的资料先放 `_索引/收件箱/`，定期整理。
5. **索引维护**：新增笔记后，在对应分类的 `README.md` 中登记一行。

## 快速开始

- 新增一条 IT 笔记 → 在 `01-IT知识/` 下建文件 → 回填 `01-IT知识/README.md` 目录表
- 用途不清的资料 → 丢进 `_索引/收件箱/`
- 跨类内容 → 归入主分类，在另一类索引中加一条跳转链接
