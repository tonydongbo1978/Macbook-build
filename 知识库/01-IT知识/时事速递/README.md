# 时事速递 · 定期机制

IT 领域重大事件的每日跟踪与月度汇总。

---

## 目录结构

```
时事速递/
├── _模板.md                        ← 日报模板（脚本据此生成）
├── README.md                       ← 本文件
├── IT重大事件-YYYY-MM-DD.md        ← 每日日报
└── 月度汇总/
    └── 月度汇总-YYYY-MM.md         ← 按月自动汇总
```

---

## 日常工作流

### ⓪ 自动生成（每日 07:00）

已配置 launchd 定时任务 `com.local.kb-digest`，每天 **07:00** 自动生成当天草稿。

```bash
# 查看状态
launchctl print gui/$(id -u)/com.local.kb-digest

# 立即手动触发一次
launchctl kickstart -p gui/$(id -u)/com.local.kb-digest
```

> ⚠️ 该任务已注册，但在 DSH 沙箱环境下实际执行受限（exit 126），
> 需在普通终端重新加载后才能生效。详见 [定时任务说明](../../scripts/定时任务说明.md)。
> 在此之前请用手动方式（下方 ①）生成。

### ① 建当天文件

```bash
python3 知识库/scripts/new_digest.py            # 今天
python3 知识库/scripts/new_digest.py 2026-10-14 # 指定日期
python3 知识库/scripts/new_digest.py --yesterday
```

生成 `IT重大事件-YYYY-MM-DD.md`，时间窗口自动填为**前一日的 09:00 → 当天 09:00（北京时间）**。

> 若当天文件已存在，脚本**默认不覆盖**并提示；确认要重填时加 `--force`。

### ② 填写内容

向 AI 提问即可，例如：

```
先搜索过去 24 小时发生的关于 IT 领域的重大事件，排名前 5，总结关键词
```

AI 按模板填入 TOP 5 事件、关键词表、趋势判断，并在文末记录**核实说明**（排除了哪些过期信息、哪些是厂商单方面说法）。

填完后把文首 `状态：草稿` 改为 `状态：完成`。

### ③ 月末汇总

```bash
python3 知识库/scripts/monthly_digest.py            # 当前月
python3 知识库/scripts/monthly_digest.py 2026-10    # 指定月份
```

自动扫描当月日报，输出 `月度汇总/月度汇总-YYYY-MM.md`，包含：

| 章节 | 内容 |
|---|---|
| 一、本月主线 | 每日「一句话总结」串成主线 |
| 二、高频关键词 | 关键词词频统计 TOP 15 |
| 三、每日事件清单 | 每天 5 条事件标题 + 日报链接 |
| 四、趋势判断汇总 | 每日趋势判断并列 |
| 五、核实与存疑记录 | 汇总各日报的核实说明 |
| 六、月度统计 | 天数、事件数、关键词数 |

---

## 写作约定

1. **每天一个文件**，文件名固定 `IT重大事件-YYYY-MM-DD.md`（脚本自动生成）。
2. **TOP 5 必须是带圈数字标题**（`### 1️⃣`…`### 5️⃣`）—— 汇总脚本靠这个正则识别事件，用普通数字或无序列表会导致统计为 0。
3. **关键词写在「关键词总结」的表格里**，每行 `| 序号 | 关键词 | 出现场景 |`，汇总脚本据此统计词频。
   - 并列关键词用 `/`、`、` 或 ` vs ` 分隔，脚本会自动拆开分别计数。
4. **一句话总结 / 一句话趋势判断各限一句**，汇总时直接引用。
5. **核实说明不可省略** —— 这是本机制最有价值的部分。搜索结果里经常混入过期新闻（如把几个月前的攻击事件当成当日热点），必须显式记录排除原因。
6. **状态标记**：新建为 `草稿`，填写完成后改 `完成`。汇总脚本会自动统计已定稿天数。

---

## 命名与统计口径

| 项目 | 约定 |
|---|---|
| 日报文件名 | `IT重大事件-YYYY-MM-DD.md` |
| 月份匹配 | 前缀匹配 `IT重大事件-YYYY-MM-` |
| 事件计数 | 仅统计 `1️⃣`–`5️⃣` 标题，草稿占位不计入 |
| 时间窗口 | 前一日 09:00 ~ 当日 09:00（北京时间） |
