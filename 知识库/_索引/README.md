## 全局标签

标签写在每篇笔记文首的 front matter 中，格式 `标签: [a, b]`。

| 标签 | 含义 | 相关分类 |
|---|---|---|
| `速查` | 高频查阅的命令 / 表格 | 全类 |
| `踩坑` | 问题排查与解决方案 | 01 / 02 / 04 |
| `教程` | 系统性入门材料 | 全类 |
| `素材` | 摘录、语料、原始资料 | 03 / 05 |
| `待补充` | 内容不完整，需后续完善 | 全类 |
