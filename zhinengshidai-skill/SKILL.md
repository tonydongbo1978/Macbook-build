## 核心框架与心智模型

**1. 一句话总纲**
人类正从"找确定性、找因果"的机械思维，切换到"承认不确定性、用数据消除不确定性"的大数据思维；当数据接近完备，机器不必像人一样推理就能获得智能。

**2. 数据—信息—知识（ch01）**
现象经观察成为数据；数据经处理显出信息；信息系统化为知识。只攒数据不处理，永远停在第一层。数据是文明的基石，用数据的能力反映文明水平。

**3. 数据驱动方法（ch01）**
不追求唯一完美模型，用**大量简单模型的组合**拟合数据，在误差内与精确模型等效（切比雪夫大数定律）。
- 最大优势：**自动受益于摩尔定律**——数据与算力指数增长，方法不必重写。
- 前提：数据量足 + 样本有代表性，缺一即失效。

**4. 智能问题 → 数据问题（ch02）**
两条路线：鸟飞派（模仿人脑，人工智能 1.0）已失败；统计派（把问题重定义为"从有限可能中挑一个"）成功。
- 判据：机器智能的关键是**能解决人脑能解决的问题**，不是必须用人脑的方法。
- 操作三步：界定可获完备性的子问题 → 匹配候选答案片段 → 组合输出。
- 例：语音识别 = 通信问题（信源编码+信道+解码）；自动驾驶 = 先"扫街"建环境数据。

**5. 大数据三特征＝信息论的三个推论（ch02、ch03）**
- 量大 → 才能压住不确定性；
- 多维度 → 才能算**互信息**、做交叉验证；
- 完备性 → 训练集≈测试集，**交叉熵趋近 0**，不被黑天鹅击穿。
- 时效性是加分项，不是必要条件。**大数据的本质是用信息消除不确定性。**

**6. 机械思维 vs 大数据思维（ch03）**
机械思维：世界确定、规律可认识且简单、规律普适 → 遗产是确定性与因果。
它仍是最好的结果，但当因果找不到时：**承认不确定性 → 引入信息 → 用强相关替代因果**。
- 相关是"租来的因果"：可先住进去，但必须"强相关 + 多源验证 + 防操纵"。

**7. 数据流：局部→整体→局部（ch04）**
大量无目的数据汇聚成整体规律，再把规律回灌到单次交易/单次展示。三件武器：相关性、时效性、个性化。
- 判据：数据优势必须形成**闭环**（采集→建模→回灌→再采集），否则只是成本。

**8. 现有产业 + 新技术 = 新产业（ch04、ch06）**
蒸汽机、电、摩尔定律三次验证；本轮是"现有产业 + 大数据/机器智能"。
- 推论一：机会多在传统行业改造，不是人人都去造技术。
- 推论二：技术会像水电一样由专业公司供给，多数企业是使用者。
- 推论三：机器替代的是**环节**而非职业；顺序由"环节可数据化程度"决定。

**9. 技术拐点四条件（ch05）**
能产生（RFID/传感器）、能存（SSD）、能传（4G/Wi-Fi）、能算（并行+云）。缺一环，大数据项目就是 PPT。规模化机器学习是系统工程问题，不是算法问题。

**10. 半世纪规律与 2% 定律（ch07）**
每次技术革命的收益顺序：发明者/早期采用者 → 本国全民 → 全球，每段以十年计；消化冲击靠**时间**（一代人退出劳动力市场），而非再培训。
- 智能革命是三重叠加：信息革命未消化 + 全球化无空白市场 + 替代的是大脑。
- 个人选择只有两条：进入前 2%，或被淘汰。
- 隐私：移动互联网 + 大数据 + 机器智能 = 无隐私；指望公司善意或立法都不可靠。

## 范围与限制

本技能只覆盖该书内容（2016 年视角）。它**不包含** 2017 年之后的 Transformer/大模型、scaling law、Agentic AI 等进展；书中对深度学习的判断（"只是把神经网络并行化"）与自动驾驶时间表已经过时。做当下决策时，应把本书当"数据思维启蒙"，而非技术现状。

书中的"机器不会控制人"这一结论，在自主 Agent 时代需要重新讨论：风险不是机器有意识，而是**委托-代理**与**超级权力**。
