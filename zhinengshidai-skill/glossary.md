# 术语表（按拼音首字母分组）

## A / B
- **安迪-比尔定律** — "比尔拿走安迪给的"：软件吃掉硬件性能提升，迫使换机，维持产业链利润（ch04）。
- **不确定性** — 世界的重要属性，来源有二：变量太多/测量不准，以及本体层面的测不准（ch03）。
- **完备性** — 某领域数据收全，使训练集≈测试集、交叉熵趋近零，不再有覆盖不到的"黑天鹅"（ch02、ch03）。

## C / D
- **大数据** — 三大特征：量大、多维度、完备性；时效性是加分项。本质是用信息消除不确定性（ch02、ch03）。
- **大数据思维** — 承认不确定性，用数据消除不确定性；找不到因果时先用强相关拿到结果（ch03）。
- **点击模型** — 用用户点击数据建的相关性模型，在搜索排序中权重可达 70%–80%（ch03）。
- **堆规则（规则派）** — 为每种情况写规则的方法论，代表是早期机器翻译的几万条语法规则（ch02）。
- **多维度（Variety）** — 大数据的正确读法；维度交叉才能做互信息与交叉验证（ch02）。

## F / G
- **服务化** — 制造利润趋零后，价值向软件、服务、数据迁移（IBM 转型）（ch04）。
- **个性化** — 从"人群平均"到"这一个人这一次"；推荐可贡献 1/3–3/4 的销售额/观看量（ch04）。
- **规模化机器学习** — 数据量大到单机放不下时，必须把参数训练拆到上万台机器的工程问题（ch05）。
- **工业 4.0** — 以数字化与智能化提升制造业（ch06）。

## H / J
- **黑天鹅** — 模型覆盖不到的小概率事件；完备性是对它的工程解（ch03）。
- **互信息** — 相关性的量化度量，"央行调利率"与"股市波动"互信息大（ch03）。
- **机械思维** — 三前提：世界确定、规律可认识且简单、规律普适；遗产是确定性 + 因果（ch03）。
- **吉尔德定律** — 多用便宜资源、少用昂贵资源；信息论第一定律的管理学推论（ch03）。
- **交叉熵 / KL 距离** — 两个概率分布一致性的度量，即"代表性"的严格量化（ch03）。
- **精细化社会** — 区块链 + RFID 使每件商品全生命周期可追溯（ch07）。
- **数据** — 可被记录与处理的符号载体；并非所有数据都承载有意义的信息（ch01）。

## L / M
- **量变到质变** — 数据量差几千上万倍时，能力跳档而非线性改进（ch02）。
- **马尔可夫模型** — 贾里尼克用来描述语音信源与信道的数学模型（ch02）。
- **蒙特卡罗树搜索** — AlphaGo 的第二个关键技术，把搜索空间限制在有限范围（ch02）。
- **模型-参数两问题** — 建模先选模型、再定参数；后者今天叫机器学习（ch01）。

## N / P
- **鸟飞派** — 以仿生为路径的方法论（看鸟怎么飞就造翅膀）（ch02）。
- **匿名化/设备识别码** — 反恐与监控共用的技术底座（ch07）。
- **平均/中位数收入** — 美国中位数收入 30 年不涨，是"技术革命收益不均"的核心证据（ch07）。

## Q / R
- **2% 定律** — 每次技术革命最初受益者约 2%；个人选择只有"进入前 2% 或被淘汰"（ch07）。
- **人工智能 1.0** — 20 世纪五六十年代表特定方法（模拟人）的 AI，区别于广义机器智能（ch02）。
- **认知不确定性 vs 本体不确定性** — 前者来自测量与变量，后者来自量子层面（ch03）。
- **日心说/地心说** — 模型选择的历史教训：都假定圆轨道，开普勒换椭圆才对（ch01、ch03）。

## S
- **熵** — 不确定性的度量，也是信息量的度量（香农）（ch03）。
- **数据驱动方法** — 先有数据、用大量简单模型拟合；自动受益于摩尔定律（ch01）。
- **数据流（局部→整体→局部）** — 汇聚成规律，再回灌到单次交易（ch04）。
- **时效性（Velocity）** — 数据即产即用，策略可分钟级调整；不是大数据的必要条件（ch02、ch04）。
- **世界知识（world knowledge）** — 消歧所需、规则无法编码的常识（pen 案例）（ch02）。
- **图灵测试** — 以"无法区分"为智能判据（ch02）。

## T / W
- **统计两要件** — 量 + 代表性；缺一即失效（ch01）。
- **完备性局部化** — 只要在"要解决的问题域"内数据完备，就能工作（如"第一页有答案"）（ch02）。
- **无隐私社会** — 移动互联网 + 大数据 + 机器智能三重叠加的结果（ch07）。
- **沃特森（Watson）** — IBM 的医疗诊断系统，无人干预时可达中等医生水平（ch06）。

## X / Y
- **信息论** — 建立在不确定性之上的方法论；三件套：熵、第一定律、第二定律（ch03）。
- **现有产业 + 新技术 = 新产业** — 蒸汽机、电、摩尔定律、大数据/机器智能三次验证的产业公式（ch04、ch06）。
- **相关性** — 让数据发挥作用的魔棒；可临时替代因果，但须"强相关 + 可验证 + 防操纵"（ch01、ch03）。
- **信噪比（SNR）** — 信号与噪声之比，决定数据可用性（ch05）。
- **涌现/组合爆炸** — 多维度数据交叉产生意外结论的机制（ch02）。
- **有限可能性** — 把智能问题改写成"从有限种可能中挑一个"，是消除不确定性的操作化定义（ch03）。

## Z
- **正交/交叉验证** — 多维信息互相印证以提高预测可靠性（ch03）。
- **智能革命** — 以大数据与机器智能为核心的第四次技术革命；冲击强于前三次（ch07）。
- **知识** — 系统化的信息，可用于改变世界；数据→信息→知识三层结构（ch01）。
- **专家系统式思维** — 认为高端脑力工作不可替代；被放射科、初级律师、财经记者的案例证伪（ch06）。
- **自主驾驶的"扫街"前提** — 先建环境数据再行驶，是"变智能问题为数据问题"的典型（ch04）。
