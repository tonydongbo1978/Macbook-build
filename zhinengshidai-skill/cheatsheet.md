# 速查表：决策规则与阈值

## 决策规则（当 X，做 Y，因为 Z）

| 当… | 做… | 因为… |
|---|---|---|
| 任务"看起来需要智能" | 先问能否改成"从有限可能中挑一个" | 智能问题多半是消除不确定性（ch03） |
| 数据量差 3 个数量级以上 | 预期能力跳档，而不是线性变好 | 量变到质变（ch02） |
| 找不到因果但必须决策 | 用强相关先跑，同时补机制 | 因果链可能耗时数十年（青霉素 30 年）（ch03） |
| 只有相关性证据 | 要求"强相关 + 多源验证 + 防操纵" | 弱相关等于赌博（ch03） |
| 模型在长尾上崩 | 查完备性/分布一致性，而不是调参 | 交叉熵大＝代表性不足（ch03） |
| 数据散落多处、存第三方 | 先修数据闭环，再谈模型 | 拼不起来的数据没有价值（ch04） |
| 想用 AI 改造业务 | 找"数据已存在但没被用"的环节 | 现有产业 + 新技术 = 新产业（ch06） |
| 想靠人工便宜维持制造优势 | 改打"全链条智能化" | 低工资优势会被智能化抹平（ch06） |
| 面临"高端脑力工作安全"的判断 | 拆环节，而非按职业判断 | 放射科/初级律师/财经记者已被替代（ch06） |
| 设计用户数据产品 | 默认最小采集 + 架构上可拒交 | 善意与立法都不可靠（ch07） |
| 规划技术投入回报 | 按"十年一代"设阶段里程碑 | 社会消化需约半个世纪（ch07） |
| 个人选方向 | 站"使用侧/定义问题侧" | 2% 定律（ch07） |

## 阈值与数字（书中给出的锚点）

- **数据量级**：差 1 万倍数据 → 从三元模型升到六元模型，翻译质量代际领先（ch02）。
- **完备性**：训练集与测试集交叉熵趋近 0，才算"完备"（ch03）。
- **相关性权重**：点击模型在搜索排序中占 70%–80%（ch03）。
- **广告信息量**：一无所知≈14 比特 → 千次展示 <0.5 美元；两个搜索词≈10–12 比特 → 千次展示≈50 美元（ch03）。
- **推荐占比**：亚马逊 1/3 销售额、Netflix 3/4 观看来自推荐（ch04）。
- **成本比**：智能诊断程序成本常不到人工的 1%；法律 AI 效率 ×500、成本 −99%（ch06）。
- **失业规模差**：通用峰值 70 万员工 vs 苹果 8 万员工，产量/市值却更高（ch07）。
- **退休负担**：通用 1 个在职工人养 4 个退休者，每车福利成本比丰田高约 1500 美元（ch07）。

## 识别信号（看到这些，说明你在错误的路上）

- 团队在**堆规则**处理长尾 → 应该是数据问题。
- 汇报里只有"总体增长 X%"，没有"哪一笔异常" → 只做了宏观统计（ch04）。
- 模型只在训练集上漂亮 → 代表性/完备性问题（ch03）。
- 大数据项目卡在"数据传不出来/存不下/算不动" → 先修四条件（ch05）。
- 隐私方案只有一纸协议 → 等于没有方案（ch05、ch07）。
- 用"这次不一样"解释 AI 冲击 → 三重叠加只会更糟（ch07）。

## 一句话判据

> **能变成数据问题的，都会变成数据问题；变不成的，才需要智能。**
